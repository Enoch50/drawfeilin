# drawfeilin 菲林自动绘制工具

## 程序说明

本程序将设计工程师导出的 DXF 图纸转化为可直接制作菲林的完整文件：
菲林图案、切割线、定位圆环、叠层对位十字架、MARK、通孔/PAD、
盛雄开孔文件、LDI 分图层文件等均由程序自动生成。

提供两种运行方式：

- **GUI 方式（推荐）**：运行 `drawfeilin_gui.py`，或双击打包后的
  `drawfeilin.exe`。无需手动编辑 config.ini，可在界面中配置、
  预览总图并一键生成。
- **命令行方式**：`python drawfeilin.py`，读取当前目录的 config.ini
  后生成。功能与 GUI 相同，但不含界面辅助。

## 输入文件

设计文件采用“图案层与通孔层分开导出”的模型：

- 图案层：文件名即图层名（如 `L1.dxf`、`L2.dxf`、`C1.dxf`、`G1.dxf`）；
- 通孔层：以 V 开头的独立文件（如 `V1.dxf`、`V5.dxf`），文件内以
  `CIRCLE` 表示孔；
- 每个数字文件夹内同时放置该型号的全部图案层与通孔层 DXF；
- 支持 `LWPOLYLINE`、`POLYLINE`、`CIRCLE`；圆弧段（bulge）在读取时
  自动离散为小线段。

## 输出文件

程序在工作目录下按用途输出到三个子目录：

- `菲林/`：总菲林 `名称(总菲林).dxf`、图层-通孔对应总图
  `名称总图N.dxf`、长通孔文件、菲林说明文件、通孔模式说明等；
- `编辑总图/`：编辑用总图 `名称编辑总图N.dxf`，把该区块原图各图层
  100% 复制到同一坐标系，供在 CAD 中直接修改图案；
- `LDI/`：按金属层拆分的 `名称-图层.dxf`；单行图案先定义成一个块
  （占位块名由程序生成），再按行阵列插入该块，向上阵列满并含外框；
  坐标原点为整版排列外框中心（200×200 外框为 ±100）；
- `开孔模式/`：盛雄开孔文件 `名称-通孔层(盛雄开孔模式).dxf`。

## 主要工艺功能

- 图案按瓷体收缩率放缩并按行列阵列；支持多种放缩率分配；
- 独立通孔层输入，通孔不依赖图案几何提取；
- 图案层与通孔层“同圆心同直径”的圆识别为 PAD 圆心，按 PAD 孔径替换；
- 图案/通孔 90 度旋转（`是否旋转90度` + `90度旋转方向` 逆/顺时针），
  并整体互换行列与切割线方向；
- 自动假引绘制已停用（假引改由人工在原图重绘）：程序不再自动复制假引
  矩形、不做引出端增绘、不自动添加假引孔；配置中的相关字段保留但不生效；
- 纯点网与独立叠层 PAD 网：层名以 `P` 开头为纯点网（不画切割线与十字架），
  以 `H` 开头为独立叠层 PAD 网（保留切割线与十字架）；规则同时用于
  LDI 与总菲林；`H` 层圆按 `PAD孔径` 绘制，`P` 层圆按 `点网孔径` 绘制；
- 自动 P 网：开启“通孔层是否增加点网”后，对没有 H 层对应的通孔层自动
  生成同名 P 层（V3→P3…），并按 `点网孔径` 输出到总菲林、LDI 与总图；
- V 层文件中人工绘制的小孔径圆（**原图孔径**小于 `假引孔阈值`）识别为
  假引孔，按自身孔径进入开孔模式，且不参与点网 PAD 绘制（菲林/LDI 与
  总图口径一致，均按原图孔径判定）；
- 引出端延伸：缩放阵列时，贴在设计外框边界的引出端顶点会按配置距离向外
  延伸（详见下文“引出端延伸逻辑”）；
- 盛雄开孔模式 1/2：模式 1 每孔按“原图孔径 × 1.1 × 2/3 + PET 圆”绘制，
  且不输出各层坐标 txt；模式 2 为分档圆/点逻辑（不变）；
- 开孔阵列满：盛雄开孔文件的孔位与 LDI 一样向上阵列满整版；
- 定位孔：开孔模式文件中的定位孔圆直径由 `定位孔孔径` 控制（默认
  0.26mm，4H/5H 共用）；菲林/LDI 的定位环标记仍按菲林英寸。
- MARK 文字、长通孔、PAD 层（P/H）、定位环、切割线、外框等按配置绘制。

## GUI 使用方法

### 界面组成

- **文件设置**：选择工作目录与 config.ini（均可浏览）；
- **配置编辑**：分页签编辑配置，页签为
  `基础参数 / 通孔 / 扩展参数 / 拼网区块 / MARK设置 / 设计规则 / 长通孔 /
  全局设置`（不常用页签后置，全局设置仍在最右）；
- **主菜单**：
  - `定位孔配置`：4H（默认，无第五定位环）/ 5H；
  - `盛雄开孔模式`：模式 1（默认）/ 模式 2；
- `图案来源`：`原图` / `编辑总图`（默认 `编辑总图`），决定生成时读取
  原始分层 DXF 还是编辑用总图，切换后立即写回 config.ini；
- **运行区按钮**：`开始生成`、`输出总图`、`生成编辑用总图`、
  `导入成型参数表…`、`打开输出目录`；下方为运行日志与生成文件列表，
  可双击打开文件。

### 常规流程

1. 选择工作目录（目录内放置数字子文件夹 1、2…，每个文件夹内为该型号
   的 DXF 文件）；
2. 选择 config.ini 并载入，按产品编辑配置后点“保存配置”；
3. （可选）点“导入成型参数表…”选择 xlsx，按表格定义总图图层顺序与配对；
4. （可选）点“生成编辑用总图”输出可编辑总图，在 CAD 中按原图层名修改
   图案（此时 `图案来源` 需为 `编辑总图`，默认已是）；
5. （可选）点“输出总图”预览排图是否正确，程序会自动打开生成的总图；
6. 确认无误后点“开始生成”，在日志与文件列表中查看结果。

### 编辑用总图（双行槽位排布）与“图案来源”开关

编辑用总图用于“先改图、再生成”的流程：程序把该区块内**全部原始图层**
（图案层 L/C/G、通孔层 V、点网层 H/P 等）复制到同一个 DXF 中，图层名与
原始文件名一致，并按**与预览总图相同的双行槽位**摆开，方便在 CAD 中直接
修改。

- **版式**：每个槽位下排是该图案层（外框+图案，中心 y=0），上排是配对
  的通孔层（外框+圆，中心 y = 设计宽 + 行距）；**上排通孔圆不会复制到
  下排图案框内**，避免干扰图案编辑；槽位横向净距 1.0mm，行距自动容纳
  一行文字；
- **文字**：下排框正下方标注图案层名，上排框下方标注通孔层名；一个通孔层
  被多个图案层共用时（如 V2 配 L1/C2/C3/C4），只在其**第一个配对槽位**
  上方绘制通孔层几何，其余配对槽位上方只写通孔层名；
- **图层颜色**：每个图层按槽位顺序分配不同颜色（沿用预览总图的色系），
  实体颜色随层（ByLayer），框下方的图层名文字也使用该层颜色，便于区分；
  顺序固定，重复生成编辑用总图时同一图层颜色不变；
- **保真**：多段线仍为多段线（圆弧已离散），输入中的圆仍写为 `CIRCLE`；
  各层原始设计外框一并写入，作为读回时的定位基准；
- **不做任何生成处理**：不旋转、不缩放、不加 PAD/假引/切割线/定位环/MARK；
- **输出位置**：`编辑总图/名称编辑总图N.dxf`（N 为数字文件夹编号），
  槽位顺序与“输出总图”一致（导入成型参数表时按表格顺序，否则按配置配对
  与文件顺序），未参与配对的图层追加在最后的槽位。

“图案来源”开关（config.ini `[EXTRA] 图案来源`，可选 `原图` / `编辑总图`）
决定 `开始生成`、`输出总图`、`设计规则检查` 读取哪一份输入：

- `编辑总图`（默认）：读取 `编辑总图/名称编辑总图N.dxf`，用户在 CAD 中的
  修改会体现在总菲林、LDI、开孔模式与设计规则检查结果中；
- `原图`：读取数字文件夹中的原始分层 DXF（即旧流程）。

注意：

- 编辑时**必须保持原图层名不变**（图层名用于配对与阵列），并且**保留每层
  的设计外框**（读回时按“外框中心=原点”定位各层；外框缺失会提示并中止）；
  在同一图层内新增实体、修改几何都会被正常读入；
- 每个图层在图中只保留一份几何；
- 选 `编辑总图` 但文件缺失、或某层找不到设计外框时会给出中文提示并中止
  生成，不会静默回退到原图；此时请先点“生成编辑用总图”，或把“图案来源”
  切回“原图”；
- 编辑用总图只显示图层名标注，不写任何版式版本标记；
- 重新生成编辑用总图会**覆盖**同名文件（用户在其中的修改会丢失），
  需要保留时请先另存。

### 成型参数表导入（xlsx）

- 不要求工作表名：自动查找任意工作表中第一行含 `层数名称` 与 `通孔模式`
  的表头（兼容旧表头 `丝网号` 与 `通孔模式说明`）；
- 总图从左到右按表中层数名称从上到下的顺序排列，只显示工作目录中实际
  存在的图案层（如 MARK、基板等无 DXF 的行自动跳过）；
- 同一行的“通孔模式”（如 V5）即该图案层的通孔配对；
  `4H`、`5H` 或空白表示该层无对应通孔层；
- 可选列 `厚度(mm)`、`切片Z(mm)`、`层类型` 供“3D切片…”使用（见下节）；
  老版表格没有这些列时导入与排图行为完全不变；
- 若表格配对与配置文件中残留的 `图层与通孔配对(实际)` 不一致，会弹窗
  提示，但仍按表格位置与配对生成总图（该配置键已不在界面显示，配对以
  表格为准）；
- 导入结果仅对本次会话生效，不写入 config.ini。

### 3D 模型切片（3D → 每层图案 DXF）

“3D切片…”把整体 3D 实体按成型参数表定义的层栈逐层取截面，直接生成
drawfeilin 可读取的分层 DXF，用于 LTCC 等叠层元器件从 3D 设计导出每层图案。

- **输入**：单个 3D 网格文件（STL/OBJ/PLY 等），Z 轴向上，单位由
  `[3D切片] 模型单位` 指定；金属图形按“有限厚度实体”、通孔按圆柱实体建模；
- **层栈**：来自“导入成型参数表…”的结果。层名以 `层数名称` 为准，该行的
  `通孔模式`（如 V5）即通孔归属层；`基板`、`MARK` 等非图层行自动跳过；
- **Z 位置**：优先用 `切片Z(mm)` 列；没有时按 `厚度(mm)`（缺失则用
  `烧结后厚度`，再缺失用 `膜厚`，膜厚按 µm 计）沿 `层序方向` 从
  `切片Z基准` 起累加。累加总厚度与模型 Z 高度偏差超过 5% 会中止并提示；
- **轮廓分类**：截面中近似圆、直径落在 `通孔直径下限`~`上限` 的轮廓写入
  对应通孔层（`CIRCLE`）；其余闭合轮廓写入图案层（闭合多段线）；尺寸与
  `产品设计x/y方向长度` 相符的轮廓按设计外框处理，不作为图案；
- **同名图层**：同一层名在表格中出现多次（同一张网印在多层）时按名称合并
  轮廓，只输出一个 DXF；
- **坐标**：按模型单位换算为 mm，并平移使模型包围盒中心落在原点；不施加
  瓷体收缩率、不旋转、不镜像（这些仍由生成阶段按 config.ini 处理）；
- **输出**：`<工作目录>/<区块号>/<层名>.dxf`；覆盖原区块目录前会整体备份为
  `<区块号>_backup_YYYYmmdd_HHMMSS/`（可用 `覆盖前备份` 关闭）；
- **STEP/IGES**：本版未实现，需先在 CAD 中另存为 STL；
- 切片完成后可“输出总图”校对排图，或“生成编辑用总图”后在 CAD 中修改。

自检脚本：`python tests/test_slice3d.py`（覆盖层栈解析、截面分类、DXF 回读
与端到端生成）。

### 总图（图层-通孔对应图）

- 下排为各图案层外框与图案（原样未旋转，便于与原图核对），框内按原始
  版式同时绘制该层对应的通孔圆（实心），框下方只标注图案层名；
- 上排为对应通孔层的独立外框与通孔圆（实心），通孔框下方标注通孔层名；
- 相邻外框净距 1.0mm，上下行净距自动容纳标注文字；
- 无配对层（如 C1/G1 或表格中 4H/5H）只保留下排图案；
- 开启“通孔层是否增加点网”后，自动生成的 P 网点网列追加在表格所有行
  之后，按通孔编号升序排列（P3、P4…）；
- 输出文件自动写入图形范围（$EXTMIN/$EXTMAX），CAD 打开即可显示全部。

### 无 config.ini 启动

当默认 config.ini 不存在时，界面仍可启动，此时仅显示“全局设置”页签的
内置默认值，其余留白；载入真实配置文件后显示完整页签。此时不能直接
“开始生成”/“输出总图”，需先载入或保存配置文件。

### 设计规则检查（最小间距 / 最小留边）

程序内置“设计规则检查”，用于检查原图各图案层是否存在间距过小或离外框留边
不足的问题（检查输入的设计坐标，不做放缩/旋转/阵列；`图案来源` 为
`编辑总图` 时检查编辑用总图中修改后的几何）。

- 间距定义：同一图层内**不同图案**之间的最小边到边距离；被包在另一轮廓内
  的轮廓视为同一图案的内部孔/内环，不计入间距。
- 留边定义：图案轮廓到本层设计外框（最大闭合矩形）内边的最小距离。
- 检查对象：图案层文件（排除 V 通孔层与 H/P 点网层）；无外框的层留边记为
  “未检查”并提示。
- 使用方式：GUI 运行区点“设计规则检查”，在“设计规则”页签或 config.ini 中
  填写规则；完成后工作目录生成 `设计规则检查报告.txt`（可用文件列表打开），
  报告含每层实测最小间距/最小留边、规则值与是否满足、最近点坐标。
- 实现说明：调研了 GitHub 现有项目（GDSViewer CLI DRC、KLayout、ezdxf、
  cad-to-shapely 等），没有可直接复用“按层最小间距+外框留边”的现成方案，
  因此本程序复用自身 DXF 解析并内置基于 Shapely 的几何检查（随 exe 打包）。

### 引出端延伸逻辑（缩放阵列时）

此逻辑与已停用的“自动假引/引出端增绘”无关：它发生在图案按放缩率放大并
阵列复制时，对贴在设计外框边界上的引出端顶点向框外延伸。

- 坐标基准：每层图案先以外框中心为原点；若开启 90° 旋转，几何按所选
  方向旋转且 X/Y 设计长度已互换。因此判断前，设计外框四边对应
  `x = ±X_LENGTH/2`、`y = ±Y_LENGTH/2`。
- 边界判断：某顶点坐标与任一边的距离小于 0.01mm，即视为“引出端顶点”。
- 缩放规则：普通顶点按该列图案的放缩率缩放（`x/x_ratio`、`y/y_ratio`）；
  引出端顶点改用瓷体收缩率缩放（`x/X_OUTLINE_RATIO`、`y/Y_OUTLINE_RATIO`）。
- 延伸规则：允许延伸的引出端顶点，在按瓷体收缩率缩放后再沿坐标符号向外
  加一个延伸距离，即 `x = x/X_OUTLINE_RATIO ± X_EXTENDED_LENGTH`、
  `y = y/Y_OUTLINE_RATIO ± Y_EXTENDED_LENGTH`；延伸量分别取
  `引出端x方向延伸距离` 与 `引出端y方向延伸距离`。
- 图层/位置规则：
  - `不做多种放缩的图层`（如 Mark）：最左列图案延伸左边与上下两边；
    最右列延伸右边与上下两边；中间列左右不延伸，但上下两边仍延伸。
  - `Outline` 层：仅按瓷体收缩率缩放，不延伸。
  - `需要做xy方向延伸的图层`：每一列的图案四边都延伸。
  - 其它图案层：最左列延伸左+上下，最右列延伸右+上下，中间列上下仍延伸、
    左右不延伸。
- Y 方向说明：无论哪一类副本，只要顶点贴在上下两边，都会按 Y 延伸距离
  向外延伸（代码中“不延伸”仅指左右方向）。

## 配置文件参数详解

程序随附 `config.ini` 模板。GUI 中编辑保存即写回该文件；命令行方式直接
编辑 config.ini。参数值写在 `=` 后，`Yes/No` 型参数只接受 Yes 或 No。

### [DEFAULT]

- `菲林转化者姓名`：菲林设计人姓名（写入说明文件与总菲林日期文字）；
- `瓷体x方向收缩率` / `瓷体y方向收缩率`：瓷体材料收缩率，一般两者相等；
- `内部图案x方向中心收缩率` / `内部图案y方向中心收缩率`：图案中心
  收缩率，一般与瓷体收缩率一致；
- `放缩率数量` / `x方向放缩率差值` / `y方向放缩率差值`：按差值生成等差
  收缩率序列，供多放缩率阵列使用；
- `产品设计x方向长度` / `产品设计y方向长度`：设计 DXF 外框尺寸（mm）；
- `菲林x方向阵列列数` / `菲林y方向阵列列数`：菲林阵列行列数；
- `引出端x方向延伸距离` / `引出端y方向延伸距离`：缩放阵列时，贴在设计
  外框边界的引出端顶点向外延伸的距离（mm），分别对应 X/Y 方向；具体
  判断与图层规则见“引出端延伸逻辑”；
- `菲林名称`：输出文件主名称；
- `假引孔阈值`：V 层中**原图孔径**小于该值（mm）的圆视为假引孔，按自身
  孔径进入开孔模式且不参与点网/PAD 绘制；默认 0.05；判定与总图一致，
  不受图案缩放率影响；
- `定位孔孔径`：开孔模式中定位孔圆的直径（mm），默认 0.26，4H/5H 共用；
  菲林/LDI/长通孔的定位环标记尺寸仍按菲林英寸，不受此参数影响；
- `是否绘制通孔层`：Yes 时在总菲林中绘制 V 通孔层图案；
- `根据通孔绘制pad`：Yes 时按“通孔与pad配对”在对应 P/H 层绘制点网圆；
- `PAD孔径`：图案层中与通孔层同圆心同直径的单独圆按此直径替换；H 层
  叠层点网圆也按此直径绘制；
- `点网孔径`：P 层点网圆的直径（含自动生成的 P 网；菲林、LDI、总图），
  只按正常通孔孔位绘制，不含假引孔；
- `通孔孔径`：通孔模型设计直径；盛雄开孔模式模式1 按“每孔原图孔径 ×
  1.1 × 2/3”绘制孔径，模式2 用于分档参考；
- `mark旋转角度` / `mark的x方向偏移` / `mark的y方向偏移` /
  `mark文字高度`：MARK 文字的角度、偏移与字高；
- `mark标识` / `表示放缩率的mark标识`：MARK 标识文字及放缩率标识序列；
- `拼网区块x方向mark标识` / `拼网区块y方向mark标识`：拼网行/列标识序列；
- `是否绘制mark标识`：Yes 时在 Mark 层绘制标识文字；
- `是否绘制长通孔dxf文件`：Yes 时输出长通孔 DXF；
- `图案全局缩放比例` / `图案原点x坐标` / `图案原点y坐标`：输入坐标统一
  缩放/平移参数，一般保持默认；
- `切割线x方向偏移距离` / `切割线y方向偏移距离`：切割线与定位环相对
  坐标原点的偏移，一般不修改；
- `菲林英寸`：菲林尺寸（6 或 8），决定定位环间距等参数；
- `不做多种放缩的图层`：不做多放缩、直接按瓷体收缩率缩放的图层名，
  用 `|` 分隔，默认含 Mark 与 Outline；这些图层在阵列时按“最左/最右/
  中间列”规则延伸引出端（Outline 例外，不延伸）。

### [EXTRA]

- `拼网列分割数` / `拼网行分割数`：拼网行列数，其乘积必须等于工作目录
  中数字文件夹数量；
- `是否镜像图层`：Yes 时图案左右镜像后再处理；
- `是否切割线内缩`：切割线与定位环对齐方式（外侧/内侧）；
- `是否输出LDI`：Yes 时生成 `LDI/` 分图层文件（默认 Yes）；
- `是否开孔阵列满`：Yes 时盛雄开孔文件孔位向上阵列满（默认 Yes）；
- `是否旋转90度`：Yes 时图案与通孔整体旋转 90° 并互换阵列行列；
- `90度旋转方向`：`逆时针`（默认）或 `顺时针`，仅在 `是否旋转90度=Yes`
  时生效；
- `通孔层是否增加点网`：Yes（默认）时对没有 H 层对应的通孔层自动生成同名
  P 点网层（Vn→Pn），按 `点网孔径` 输出到总菲林、LDI、总图；已有 H/P
  配对优先，不重复生成；
- `图案来源`：`编辑总图`（默认）或 `原图`，决定生成/预览/规则检查读取
  编辑用总图还是原始分层 DXF（详见“编辑用总图”）；旧配置缺少该键时按
  `编辑总图` 处理；
- `是否引出端增绘`：自动引出端增绘已停用（假引人工重绘），保留字段
  以兼容旧配置，不影响生成结果。

### [LONGTHROUGHHOLE]

- `长通孔孔径`：长通孔圆直径；
- `长通孔列表`：需输出长通孔文件的通孔层名，用 `|` 分隔；
- `长通孔模式是否镜像`：Yes 时镜像整个长通孔模式。

### [设计规则]

- `是否启用`：Yes 时“设计规则检查”按本节规则判定；No 时报告标注未启用；
- `默认最小间距` / `默认最小留边量`：未单独指定的图层使用的默认规则值（mm）；
- `图层规则`：按图层覆盖默认值，多项用 `;` 分隔，每项 `层名|最小间距|最小留边量`，
  如 `L1|0.08|0.05;L2|0.1|-`；某项留空或写 `-` 表示沿用默认值。

### [3D切片]

- `模型单位`：3D 模型文件单位，可选 `mm`/`cm`/`m`/`inch`/`mil`/`um`；
- `切片采样容差`：图案轮廓简化容差（mm），越小越贴合模型、顶点越多；
- `通孔直径下限` / `通孔直径上限`：判定为通孔并写成 `CIRCLE` 的直径区间（mm）；
- `近圆判定长宽比` / `圆度下限`：截面轮廓是否视为圆的判定阈值；
- `层序方向`：`自上而下`（表格第一行在最上方）或 `自下而上`；
- `切片Z基准`：层栈起始 Z（mm）；留空表示自上而下取模型顶面、自下而上取底面；
- `覆盖前备份`：Yes 时切片覆盖原区块目录前整体备份。

### [拼网区块 N]（N 对应数字文件夹）

- `型号名称`：该区块型号名称；
- `通孔与pad配对`：通孔层与 P/H 层对应（如 `V3|H3,V5|P5`）；留空表示
  不绘制 PAD。

拼网区块页签只保留以上两项。原先的 `需要做xy方向延伸的图层`、
`图层与通孔配对(实际)`、`需要绘制假引的图层`、`绘制假引孔的图层` 已从
界面与模板中移除：图层配对请以“导入成型参数表”为准，假引由人工在 V 层
绘制小孔径圆（程序按 `假引孔阈值` 自动识别）。核心仍兼容手工写回这些键
的旧配置，但 GUI 保存配置时会移除它们。

## 注意事项

- 运行前确认工作目录数字文件夹数量与 `拼网列分割数 × 拼网行分割数`
  一致，否则程序会拒绝生成并提示；
- 总图文件若正被 CAD 打开，重新生成会提示文件被占用，先关闭再生成；
- GUI 中改参数后请先“保存配置”再生成；“输出总图”只生成总图用于预览，
  “开始生成”才会输出全部文件；默认 `图案来源 = 编辑总图`，首次使用或
  更换输入文件后需先“生成编辑用总图”，否则生成会被中止并提示；
- “3D切片…”依赖 `trimesh` 与 `shapely`（打包版已内置；源码运行需
  `pip install trimesh shapely`），STEP/IGES 模型请先另存为 STL；
- 本程序为 Windows 简体中文环境设计，不使用任何第三方绘图库，GUI 仅依赖
  标准库与 openpyxl（读取成型参数表）。
